six-word-story is a tiny program that writes one complete story in exactly six words to a file: an acceptance in three words — "She said yes." — answered by a parting in three more — "He said goodbye." What she agreed to, and why he left, are left for the reader to fill in.

## Run it

```sh
python3 main.py
```

It writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
